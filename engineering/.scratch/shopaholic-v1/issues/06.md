# 06 — Replace universal L1-L4 truth ranking with claim-specific evidence roles

**What to build:** Route sources by what they can prove: regulatory, official primary, independent measurement, field/repair, corporate registry, and market/price.

**Blocked by:** 05

**Status:** ready-for-agent

## Acceptance criteria

- [ ] Source role is stored independently from claim confidence.
- [ ] Seller price is valid market evidence but not durability evidence.
- [ ] Official spec can strongly support declared dimension without proving superiority.
- [ ] No fixed source-count requirement determines confidence.

## Verification procedure

Pass: seller offer supports price; official manual supports feature; independent test supports measured performance. Adversarial: ten seller pages asserting durability cannot upgrade a high-impact comparative claim to verified.

Always execute verification in a fresh context. Save the exact prompt/input, raw output, structured record if available, tool/source trace, and pass/fail rationale. Include at least one expected-pass path and the adversarial path above. Do not repair a failed output before scoring.
