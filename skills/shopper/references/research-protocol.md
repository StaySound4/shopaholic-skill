# 代理式购物研究协议与 4-Lane 调研模型

仅在需要从市场发现候选、核验当前在售状态、完成复杂对比或处理高风险商品时读取。

## 目标与原则

在与决策价值匹配的成本内，进行全网**高广度、高深度、高信度**的循证检索：
**行业前置深研 → 实体对齐 → 4轨并行核验 → 文献与标准溯源 → 来源谱系去重 → 反证与通病复查 → 决策分层**。
广度以覆盖主流、长尾品牌与全部技术路线为准；深度以穿透底层工艺、供应链元器件、行业标准、失败模式与通病为准。

---

## 阶段零：行业与品类前置深研（先调研，后提问）

在接触任何消费品或商品推荐需求时，**必须先完成前置行业深研**，建立该品类的立体认知，严禁在未做检索的情况下直接向用户抛出泛化问卷。

### 1. 行业与制造工艺深研
- 查明该品类的底层物理/化学/制造原理（如冷冻升华干燥 vs 喷雾干燥；OLED 像素排列 vs Mini-LED 背光分区；热泵压缩机 vs 冷凝烘干）。
- 梳理上游核心元器件/原材料供应链（如面板厂商、传感器型号、咖啡豆种产区、电机类型、面料克重与织法）。
- 厘清全生命周期成本（耗材单价、更换周期、保外维修费、残值折旧）。

### 2. 权威标准与文献溯源（借鉴 Literature-Review 范式）
- **国家与行业强制标准**：检索国家标准（GB、GB/T）、团体标准（T/CASME 等）、行业白皮书。
- **国际权威机构与安全评估**：对食品、母婴、美妆个护、医疗器械等高敏品类，查阅 FDA、EFSA、WHO、SGS、CMA 等权威机构的安全耐受量、毒理报告与检测方法。
- **核心专利与专有技术**：检索品牌声称的专有工艺（如冷萃超频提取、微米级结晶、纳米涂层），核实属于真实技术专利还是纯粹营销包装名词。

### 3. 极简提问门槛（若无互斥分歧则直接输出）
- **严禁询问预算**：用户需要预算限制时会主动说明；未说明时以多梯队覆盖全价格带。
- 仅在技术路线完全互斥（如冷萃即溶便携 vs 深度烘焙配奶大罐；轻薄长续航 vs 极限性能释放）且无法单次自然覆盖时，发起最多 1~2 个极简选择题。

## 4-Lane 并行深度核验协议

在进行候选发现与深度比对时，按照 4 个专业视角（无论是由主代理分步顺序执行，还是在支持并发的智能体框架下并行分工）进行：
### Lane 1：市场全景与新锐候选发现（Market Scouting）
- **广度覆盖**：目标市场当前全部主流品牌、新锐黑马、行业老牌及代工自有品牌。
- **价格带与形态覆盖**：入门平价口粮、中端主力、高端旗舰及差异化小众形态。
- **实体锁定**：记录完整品牌原名、型号全称、标准 SKU、平台与销售渠道、抓取日期。

### Lane 2：规格、工艺与标准溯源（Specs & Standards）
- **官方规格与说明书**：额定功率、核心尺寸、材质成分、认证编号（CCC、卫食健字、医疗器械注册证）。
- **供应链穿透**：核心部件/原料的真实供应方与等级（如屏幕供应商、芯片制程、生豆等级）。
- **营销去伪存真**：剔除“太空科技、纳米级、纯天然、医美级、独家秘方”等虚假溢价词。

### Lane 3：独立实测、拆解与客诉通病（Teardowns & Lab Tests）
- **独立拆解与实测**：查找有明确实验方法、仪器测量、原始数据和拆机图的第三方测评（重点看内部用料、做工、散热设计、电路保护）。
- **长期耐用性与老化表现**：搜索 6~12 个月以上的长期使用反馈、密封圈老化、涂层脱落、电池衰减、风味变质等情况。
- **高频故障与客诉集中点**：黑猫投诉、维权论坛、专业社区中反馈的装配公差、异响、漏液、断裂等硬件暗病。

### Lane 4：反证复查与信息污染清理（Antithesis & Anti-Pollution）
- **反向关键词搜索**：对拟推荐候选执行定向反查：
  - `[品牌型号] + 缺点 / 通病 / 翻车 / 智商税 / 差评 / 虚标 / 拒保 / 降级 / 缩水 / 批次问题`
  - **静默改版与缩水核查**：对上市半年以上的成熟爆款，定向检索 `[型号] + 偷偷换芯 / 偷偷降级 / 新旧版本差异 / 缩水 / 减配`，核实是否存在详情页沿用老款好评但内部用料变差的情况。
- **信息污染剥离**：识别并剔除好评返现、MCN 种草矩阵、SEO 站群软文、同质化公关稿，追溯原始实测数据源。

## 决策分层与综合裁决

主代理汇集 4-Lane 证据后执行：
1. **同源证据去重**：合并同一公关稿或同一分销联盟的多平台转载。
2. **红线一票否决**：存在安全隐患、国标不达标、重大批量性设计缺陷的型号直接移入“第四类（淘汰/不建议）”。
3. **分层推荐矩阵**：
   - **第一梯队（优先推荐）**：各维度表现顶尖、独立实测与拆解证据确凿、翻车率极低。无任何独立实测证据或全网仅有单向营销好评的“黑盒产品”，严禁进入第一梯队。
   - **第二梯队（平价口粮/高性价比/待进一步验证）**：核心功能达标，安全合规，在次要材质或边缘体验有合理妥协；或一般性能优秀但缺乏长周期耐用性拆解数据的成熟产品。
   - **第三梯队（特定条件选择）**：在特定偏好或小众场景下优势显著，但存在明确代价（需写明触发条件与牺牲项）。
   - **第四类（淘汰/不建议）**：存在严重虚标、隐蔽减配、同类通病多发、智商税严重或有明显更稳妥平替。

## 自检与防翻车清单

输出前逐项核对：
- [ ] 是否已向用户普及该品类最容易踩坑的 2~3 个隐蔽雷点？
- [ ] 推荐表格中是否**强制列出每个候选的真实缺点、通病或已知翻车点**（严禁只夸不贬）？
- [ ] 推荐的产品是否经过反证复查，而非只看正面宣传？
- [ ] 是否提供了下单防买错与收货验货的实操防翻车清单？
