# 信源分级、内容防污染与电商风险核验体系

仅在需要检索、核验价格/评论/评测/直播/售后或处理高风险商品时读取。

---

## 一、 信源可信度四级金字塔与采信规则

网络上的导购信息、评测博客与问答社区充斥着大量商单、返利外链与水军软文。智能体在检索取证时，必须严格执行**信源可信度四级分级体系**，严禁将低信度营销内容作为决定性证据：

```
                    ┌───────────────────────────────────────────────┐
                    │  L1 级：法定资质与权威硬数据 (最高信度/绝对基准) │
                    │  - 国家/行业标准 (GB/T, QB/T, YY)、3C 认证编号  │
                    │  - 药监局批文、质检抽检公告、官方白皮书铭牌参数 │
                    └───────────────────────┬───────────────────────┘
                                            │
                    ┌───────────────────────┴───────────────────────┐
                    │  L2 级：高质量独立拆解与实测 (高信度/方法透明) │
                    │  - 自购样机、有完整测试环境/仪器/原始测量数据   │
                    │  - 明确指出产品故障案例、做工妥协与核心短板     │
                    └───────────────────────┬───────────────────────┘
                                            │
                    ┌───────────────────────┴───────────────────────┐
                    │  L3 级：真实多方客诉与使用反馈 (中信度/动态校准)│
                    │  - 维权投诉平台、垂直论坛长周期(3~12月)使用追评 │
                    │  - 执行双轨判定：致命缺陷1起即警示，一般通病按保有量评估 │
                    │  - 依赖市场保有量基数，冷门无差评强制标注未经验证 │
                    └───────────────────────┬───────────────────────┘
                                            │
                    ┌───────────────────────┴───────────────────────┐
                    │  L4 级：高风险商业推广与水军矩阵 (低信度/严格过滤)│
                    │  - 知乎/百度知道/贴吧/小红书导购软文、返利榜单  │
                    │  - 仅用于发掘市场在售候选 SKU，严禁支撑推荐排名 │
                    └───────────────────────────────────────────────┘
```

| 证据等级 | 代表性信源形态 | 采信与处理准则 |
|---|---|---|
| **L1 级（法定与官方硬数据）** | 国家标准全文（GB/T 等）、认监委 3C 认证库、国家药监局注册备案（国妆特字/医疗器械）、质检总局抽检公告、官方技术白皮书。 | **核心判据**。用于判定合规门槛、安全限量、基础物理规格与是否涉及批次召回。 |
| **L2 级（专业独立拆解/实测）** | 具备自购说明、标准化测试环境、高精度仪器原始数据、高清内部拆机图，并明确呈现测试失败案例与做工妥协的第三方深度评测。 | **推荐支撑**。用于核验内部真实用料、散热做工与持续工况性能。**防特挑样机**：明确区分量产零售机拆解与送测样机/单一样本评测；冷门小众品牌的单一评测仅能证明“设计上限”，不能证明“量产品控下限”。 |
| **L3 级（长周期真实使用反馈）** | 垂直技术论坛长帖、黑猫投诉维权归因、电商平台 3~12 个月追评、维修师傅拆修记录。 | **风险预警**。用于排查装配公差、虚焊、断轴、老化等高频暗病。**依赖保有量基数**：执行双轨判定机制（致命缺陷 1 起即警示；一般缺陷主流款 3 起以上判定为通病，冷门款 1~2 起标记为批次公差风险）。低销量无差评强制标注未经验证。 |
| **L4 级（商业软广与泛社交社区）** | 知乎/贴吧/百度知道/小红书中的“好物清单”、“神仙好物”、“闭眼入”、Top10 返利榜单、无测试步骤的纯开箱晒图。 | **严格过滤**。此级内容 90% 以上带有分销佣金（Affiliate）或商业合作属性，**仅可作为市场在售型号的发现线索，绝对禁止直接采信其排名或结论**。 |

### 信源数量底线与双重佐证准则 (Citation Quotas & Dual Sourcing)
1. **信源覆盖总量**：全案研究中，普通消费品类全网独立有效信源数 $\ge 8$ 条；高风险/数码电器/大家电/母婴/医疗器械类 $\ge 10$ 条。
2. **双重佐证强制要求**：核心候选的物理参数与内部用料必须具备 **L1 级官方规格 + L2 级独立实测** 的交叉印证，杜绝单一自述或商业软广孤证。

## 二、 双轨证据分档准入标准与 BOM 白盒化防线

为了既不误杀刚上市的高用料硬核新品（如刚发布的旗舰），又防止水军把偷工减料的贴牌白牌吹捧上榜，推荐候选池强制执行**双轨制分档矩阵**：

### 1. 【A 档：大样本成熟验证池】准入硬标准
- **市场在售周期**：通常公开发售 $\ge 6$ 个月；
- **样本量门槛**：主流电商大样本（累计销量/真实评价规模达标），具备 $\ge 3$ 个独立技术机构的量产拆解；
- **售后保障**：拥有全国联保或成熟的自营/签约官方售后履约网络；
- **定位**：推荐给追求绝对稳妥、买后省心、不愿承担早期品控与软件迭代波动的绝大多数普通用户。

### 2. 【B 档：高潜能·硬核新品/黑马观察池】准入硬标准（BOM 白盒化）
严禁仅凭发布会 PPT 或 KOL 宣传将产品列入 B 档，必须同时满足以下 3 条**白盒化硬指标**：
1. **硬件物料清单（BOM）完全白盒化**：
   - 核心元器件必须明确品牌与具体型号（如 CMOS 传感器具体型号、主控芯片纳米制程、屏幕面板代际与背光分区数、电机/压缩机品牌排量），黑盒组装直接一票否决；
2. **量产零售机 L2 级独立拆解或实测佐证**：
   - 必须至少由 1 家具备仪器测量能力的独立评测机构完成过零售机拆解（确认内部电路防护、散热用料与焊点做工扎实）；
3. **强制附加【成熟度与售后妥协声明】**：
   - 报告中必须明确向用户披露：“*该机型处于新品/小众观察期，硬件用料扎实，但软件算法生态仍在快速迭代，长期耐用度与批次装配公差仍在观测，售后通路以官方寄修为主*”。

## 三、 冷门长尾、白牌贴牌与幸存者偏差防御机制

面对出货量低、知名度小、长尾小众或贴牌代工的商品，必须启动专项防御机制：

### 1. 证据缺失谬误防线 (Absence of Evidence Rule)
- **核心公式**：`低销量 + 零负面反馈 = 长期耐用度与批次一致性未经验证 (Unverified)`，严禁直接判定为 `品控优良 (High Quality)`。
- **信息盲区穿透**：低保有量商品缺乏大样本真实用户洗礼，其零差评往往源于“样本基数过小”而非“产品零缺陷”。凡全网缺乏长期规模化真实追评与独立量产拆解的产品，必须强制施加置信度折损，严禁直接推选为【第一梯队·大众稳妥首选】。

### 2. 缺陷严重度双轨触发机制 (Severity-Based Alert Protocol)
- **一级缺陷（致命级·Safety & Core Critical）**：
  - *涵盖范围*：自燃起火、高压击穿、重金属/有害化学物质超标、主板短路烧毁、承重核心结构断裂、关键保护失效。
  - *触发阈值*：**全网检索到 1 起真实案例即触发高危预警**。不设保有量门槛，必须在推荐报告的落选说明或风险清单中置顶披露并执行一票否决。
- **二级缺陷（体验级·Quality & Tolerances）**：
  - *涵盖范围*：装配公差缝隙、偶发轻微异响、按键虚位、漆面脱落、软件偶发小 Bug。
  - *触发阈值*：主流高销量商品维持 $\ge 3$ 起同类归因判定为通病；低保有量小众商品若有 1~2 起，直接定性为“批次一致性与装配公差存疑”，并在置信度说明中明确提示。

### 3. 售后通路与后勤保障透明度核验
选购对比时必须核实并明确标注该商品的实际售后通路形态：
1. **全国联保（官方上门）**：品牌自建或官方签约网点，支持全国上门检测维修（保障等级：高）。
2. **品牌寄修（官方履约）**：由品牌官方售后中心统一寄修，明确往返运费承担规则（保障等级：中）。
3. **第三方外包网点**：无自建售后，外包给第三方综合维修点，服务质量与配件原厂度波动较大。
4. **店铺单方质保（高危孤儿机）**：无品牌官方售后，完全依赖单一电商店铺自行维修。必须明确提示：**“网店倒闭或退店后将彻底失去保修兜底”**。

## 四、 社区软广、导购博客与伪 UGC 识别过滤清单

在检索知乎、百度知道、百度贴吧、小红书及各类导购博客时，一旦命中以下特征，自动判定为高风险商业软广并降级处理：
- **虚构第一人称痛点**：以“最近很多朋友/粉丝问我...”、“给闺蜜/爸妈挑了半天最后选了...”开篇，后文无任何测试数据直接给出产品链接。
- **极端情绪化与绝对化修饰**：频繁出现“闭眼入”、“天花板”、“同价位无敌”、“按头安利”、“后悔没早买”等缺乏实证支撑的形容词。
- **无痛痒“伪缺点”掩护**：评测文章假装客观列出缺点，但全是“包装盒太大”、“颜色太好看挑花眼”、“功能太多要看说明书”等无关痛痒的假缺点，刻意回避核心发热、噪音、材质缩水与售后翻车问题。
- **分销返利参数外链**：文章所有购买跳转链接均携带推广佣金参数（如 `?tag=`, `?aff=`, `&ref=`, `cps` 联盟代码）。
