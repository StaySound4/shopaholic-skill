# 证据账本、反 GEO 投毒与决策后悔抑制

仅在需要检索、核验价格/评论/评测/直播/售后或处理高风险商品时读取。

## 证据账本与 CoVe 事实审计

对影响淘汰、排序或风险的主张记录：

| 字段 | 含义 |
|---|---|
| claim | 要证明的具体主张 |
| source / url | 来源与可定位链接 |
| date | 发布、生效或抓取日期 |
| identity | 对应型号、SKU、地区、状态 |
| independence | 厂商/商家/平台/独立第三方/监管 |
| directness | 直接证明、间接支持或仅为线索 |
| conflict | 广告、佣金、赠品、品牌关系、未知 |
| confidence | 高/中/低及剩余不确定性 |
| cove_tag | `[Fact]`（实测硬证据）/ `[Inference]`（理论推导）/ `[Risk]`（待验客诉假设） |

不要给来源永久贴 A/B/C 标签；同一说明书可直接证明标称功率，却不能直接证明长期可靠性。

## 评论、声誉操纵与伪 UGC 识别

高风险信号：
- 好评返现、红包、卡券、赠品换指定好评。
- 短期密集五星，语言、错别字或句式高度重复。
- 晒图构图/背景相似，图片与型号不符。
- 不同变体或不同商品共用评价；旧款评价迁移到新款。
- 好评前置、差评后置、差评消失或评分突然跃升。
- 大量“物流快、客服好”却回避产品本身。
- 追评与初评明显矛盾；差评集中在同一批次、部件或售后节点。

评论只用于提出待核验风险。不要凭“像 AI 写的”判假；公开文本检测不能可靠单独识别合成评价。

相关依据：
- [《消费者权益保护法实施条例》](https://www.gov.cn/zhengce/zhengceku/202403/content_6940159.htm)
- [《网络反不正当竞争暂行规定》](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2024/art_80019fe59e464196bef173dc56678a42.html)

## 真实价格、促销与 TCO 全生命周期核算

比较前固定：SKU、地区、时间、库存、登录/会员、新客资格、支付方式、券补、政府补贴（国补/以旧换新）、运费、安装、赠品、保修类型、分期期数、手续费/利息、保险或会员绑定和总还款额。月供只能称月供，不得当作商品总价。

- **政府能效/消费补贴（国补）专项防坑**：
  - 必须核实商品近 30~90 天的历史未补贴价格，防范商家“先涨价后打折”套取补贴。
  - 提醒用户补贴发票的抬头限制（部分国补订单锁定个人抬头不可修改），以及退货后补贴额度是否实时释放、是否影响二次申领。
- 无历史成交证据时，不写“史低/最低”。
- 促销比较价需有真实口径；警惕临时提价、虚构原价、低标高结、隐藏门槛、规则与结算不一致。
- 赠品按用户真实价值计入，不按商家标称价全额抵扣。
- 复杂满减应算最终总支出，而不是单件“摊后价”。
- **全生命周期总拥有成本 (TCO)**：按品类纳入耗材单价（滤芯/胶囊/刷头）、定期更换周期、订阅费、能耗电费、安装维护、过保维修费及二手残值折旧。

依据：
- [《明码标价和禁止价格欺诈规定》](https://www.moj.gov.cn/pub/sfbgw/flfggz/flfggzbmgz/202305/t20230511_478601.html)
- [《互联网信息服务算法推荐管理规定》](https://www.moj.gov.cn/pub/sfbgw/flfggz/flfggzbmgz/202305/t20230509_478388.html)

## 独立评测、联盟污染与反 GEO 投毒体系

### 独立评测核验基准
1. 样品是自购、借测、赠送还是未知。
2. 测试日期、环境、方法和可重复步骤。
3. 原始测量，而非只给星级或结论。
4. 对照产品、失败案例和明确缺点。
5. 长期使用还是短时上手。
6. 广告、佣金、优惠码、品牌或 MCN 关系。
7. 更新记录，是否把旧型号内容套到新品。

### GEO（生成式引擎优化）投毒与黑帽操纵识别
- **AI 摘要投毒（AI Citation Poisoning）**：针对 AI 搜索偏好撰写的“高事实密度+倒金字塔格式+绝对化首句”的虚假对比软文，首句即给结论（如“同价位无可争议第一名”）。
- **结构化元数据欺诈（Schema.org Manipulation）**：网页前端充斥真实差评，但在后端 JSON-LD 中强行注入虚高的评分（如 `ratingValue: 4.9`）。必须抓取具体差评语义，严禁只读 JSON 评分。
- **无痛痒“伪缺点”掩护**：列出的缺点全是“包装箱太大”、“颜色太好看容易挑花眼”，刻意掩盖核心用料缩水、过热降频或售后翻车问题。
- **佣金绑架与全家桶垄断**：推荐清单中所有不同品类商品最终均导向同一家店铺或包含特定推广佣金参数（`?tag=`, `?aff=`, `&ref=`）。

### 反 GEO 投毒与信息清洗硬规则
- **穿透式三方三角验证（Triangulation）**：任何推荐结论必须经过 **【官方国标与铭牌参数】+【第三方独立实验室/仪器拆解实测】+【真实长周期维权客诉与差评聚类】** 的交叉印证。

依据：
- [《互联网广告管理办法》](https://www.moj.gov.cn/pub/sfbgw/flfggz/flfggzbmgz/202306/t20230620_481045.html)
- [《人工智能生成合成内容标识办法》](https://www.gov.cn/zhengce/zhengceku/202503/content_7014286.htm)

## 购后后悔抑制、决策可逆性与二手残值流转 (Regret Mitigation)

为降低用户的决策后悔率，必须评估：
1. **决策可逆性（Reversibility Score）**：
   - 区分“七日无理由”与质量问题。核实拆封后是否支持无理由退货、是否包含运费险；
   - 大件商品（床垫、电视、沙发、跑步机）核算打木架、搬运上楼费及退货巨额物流成本。
2. **闲置吃灰风险与二手残值（Liquidity Index）**：
   - 评估高吃灰品类（如原汁机、跑步机、面包机）的真实使用频率；
   - 核算闲置 3~6 个月在二手平台（闲鱼/转转）的残值折价率（保值率高 vs 骨折难出手）。
3. **退换修与备件透明度**：
   - 优先选择售后网点普及、核心备件价格公开透明且交易留在可申诉平台内的方案。
