## 🔍 核心机制：品类前置知识检索是如何进行的？

与传统大模型直接调取模糊记忆不同，Shopaholic 在接触到任何具体商品前，必须先在后台执行**阶段零：品类底层知识前置检索（Phase 0: Domain Pre-Research）**，建立该品类的客观物理标尺：

```
                ┌─────────────────────────────────────────────────────────────┐
                │        【阶段零：品类前置知识检索 (后台自动化执行)】          │
                └──────────────────────────────┬──────────────────────────────┘
                                               │
        ┌──────────────────────────────────────┼──────────────────────────────────────┐
        ▼                                      ▼                                      ▼
【1. 物理/化学制造原理】               【2. 公开标准与安全基准】              【3. 生命周期成本与暗病】
- 查明核心零部件与材料规格             - 查阅适用的国家/行业公开标准          - 核算专用耗材后续单价与更换频次
  (如 Fast-IPS 原厂面板封装、           (如 3C 认证规范、食品接触材质标准、     - 检索垂直论坛 3~12 个月长期反馈
   PID 电子温控、双驱割毛刀)             能效等级及安全限量)                   - 评估日常打理门槛与闲置吃灰率
        │                                      │                                      │
        └──────────────────────────────────────┼──────────────────────────────────────┘
                                               │
                                               ▼
                ┌─────────────────────────────────────────────────────────────┐
                │          【形成客观评测基准，再进入具体型号分析与交互】         │

```

1. **查制造工艺与核心部件**：先查清该品类决定体验与寿命的物理本质（如热泵压缩机 vs 冷凝烘干；原生 GtG 响应时间 vs 伤眼的 MPRT 插黑帧；金属平刀 vs 陶瓷锥刀）。
2. **查公开法定标准与安全基准**：查阅适用的国家标准（GB/T）、行业标准（QB/T）与安全认证要求，辨别商家自封的宣传噱头与真实的合规底线。
3. **查生命周期成本与共性暗病**：核算后续滤芯/胶囊等专用耗材成本，并检索长周期客诉排查装配公差、虚焊、断轴、密封圈老化等共性问题。

## 💡 核心定位与解决的 5 大消费痛点

**Shopaholic 的核心使命是通过循证科学与供应链常识，重构消费者的自主选购判断力。**

| 常见选购困扰 | Shopaholic 解决方式与收益 |
|---|---|
| **需求不明确，不知从何选起** | **先问再买**：识别尺寸、人数、材质等关键限制，先澄清核心边界再精准缩小范围 |
| **营销名词太多，看不懂实际区别** | **原理拆解**：用通俗语言讲清底层物理用料与工艺差异，学会品类判断逻辑 |
| **全是好评，不知道有没有隐蔽缺点** | **如实披露**：结合拆解数据与多方用户长期反馈，直击潜在短板与通病 |
| **热销爆款不知是否适合自己** | **反事实说明**：客观讲清某热门款为何未被列入首选，打消选购疑虑 |
| **机器很便宜，耗材极贵** | **全生命周期核算**：综合评估专用耗材价格、大件退换运费以及容易吃灰闲置的概率 |

## 📱 实战效果演示（典型场景实录）

### 场景一：需求模糊时的前置提问（模式 A：先问再买 · 咖啡机案例）

```text
用户       ❯ 推荐个咖啡机。

Shopaholic ❯ 【先别急着买：这几个变量会直接改变答案】
             
             经过对咖啡机品类（半自动/全自动/胶囊/滴滤）的底层打理与萃取机制分析，目前缺少几个决定选型的核心变量：
             1. 日常主要饮用场景与打理意愿：是追求“工作日早八 1 分钟快速提神”，还是愿意“花 10 分钟称豆、布粉、压粉并冲洗手柄”？（半自动机器若无打理习惯，3 个月内闲置吃灰率极高；早八提神更适合全自动或胶囊机）
             2. 核心偏好品类：常喝黑咖啡（美式、冷萃），还是重度拿铁/卡布奇诺奶咖爱好者？（纯黑咖滴滤/胶囊即可满足；优质奶咖需要强劲蒸汽锅炉或高效自动奶泡系统）
             3. 长期单杯耗材成本预期：是否接受单颗 ¥3.5~¥5 的原装胶囊成本？（如果日均 2~3 杯，胶囊年耗材可达数千元，全自动使用商业咖啡豆单杯仅需 ¥1~¥1.5）

             明确上述核心习惯后，我会为你快速锁定最匹配的在售代表机型。
```

### 场景二：千元电竞显示器推荐（模式 B：执行推荐 · 讲透核心参数与妥协）

```text
用户       ❯ 想买个千元左右的 2K 电竞显示器，主玩 FPS 兼顾日常办公。

Shopaholic ❯ 【显示器核心选购逻辑】
             千元电竞显示器重点看 3 点，避免被噱头误导：
             1. 认准原生 GtG 响应时间：警惕宣传的“1ms MPRT”（实质为插黑帧动态模糊消除，会引发不可见频闪造成眼睛干涩疲劳）；
             2. 面板封装与调光：优先选择原厂 Fast-IPS 面板封装与全亮度 DC 调光（硬件级低蓝光波峰在 455nm 以上更护眼）；
             3. 支架做工与接口带宽：千元机普遍在模具塑料和支架调节上缩水，需关注是否支持升降旋转或标配 DP 1.4。

             【分层参考建议（代称展示）】
             • 方案 A（FPS 电竞响应优先型 · 参考价约 ¥999）：
               - 优势：原厂 Fast-IPS 调校，真实 GtG 响应约 1.5ms 拖影极小，支持硬件低蓝光。
               - 短板与妥协：全黑背景下四角存在轻微 IPS 漏光（属于品类正常物理特性），外壳塑料感偏明显。
             • 方案 B（色彩办公兼顾型 · 参考价约 ¥1,099）：
               - 优势：覆盖 99% sRGB 色域且出厂校色 ΔE<2，配备全功能升降旋转支架。
               - 短板与妥协：极限高刷响应时间略慢于方案 A，更适合兼顾修图与竞技。

             • 某热销网红款为什么未被列入首选：
               - 该型号虽然宣传 240Hz，但实测开启最高响应档位后存在明显的“鬼影/像素过冲（Overshoot）”，且采用非 DC 调光，长久注视易眼疲劳。

             【验货清单】到手后使用全黑/全白纯色背景，检查坏点数量与严重漏光，并在显卡控制面板开启 G-Sync/FreeSync 排查撕裂。
```

### 场景三：扫地机器人两款淘汰终审（模式 D：候选终审 · 结构化裁决）

```text
用户       ❯ 我看中了 [机型 A] 和 [机型 B]，都是两千多元的扫地机器人，帮我终审淘汰一个。

Shopaholic ❯ 【候选终审裁决】

             | 候选机型 | 终审结论 | 核心判定原因与用料差异 | 潜在风险提示 |
             |---|---|---|---|
             | **机型 A** | **保留 (优先建议)** | 采用双目 AI 结构光避障 + 纯胶刷对向防缠绕设计；基站配备 55℃ 热风烘干，梅雨季拖布不易发霉异味。 | 机身高度约 9.8cm，低于 10cm 的超矮沙发底部可能无法进入。 |
             | **机型 B** | **淘汰** | 虽然标称吸力数值略高，但采用传统“胶毛一体刷”，长头发极易在轴承两端死死缠死；且基站仅支持冷风慢干，湿度大时容易发臭。 | 基站底盘为一体式不可拆卸，使用半年后清洁死角容易积泥生菌。 |

             【最终建议】：保留 **机型 A**。扫地机日常省心程度主要取决于“毛发是否需要频繁手剪”和“拖布烘干是否发臭”，机型 A 的机械结构更合理。
```

## 🧭 决策流程与四大工作模式

**Shopaholic 根据用户的输入状态与信息完整度，自适应触发四大工作模式：**

```
                    [ 收到用户选购需求与咨询 ]
                                │
              ┌─────────────────┴─────────────────┐
              ▼                                   ▼
       【需求不够明确】                    【需求相对明确】
              │                                   │
              ▼                                   ▼
     模式 A：先问再买                    模式 B：执行推荐
     - 提出 2~5 个关键澄清问题           - 核心工艺与物理原理科普
     - 解释变量为何改变选型结果          - 4-Lane 交叉核验矩阵
     - 提示盲买易踩的尺寸/场景坑          - 优缺点如实披露 + 避坑清单
                                                  │
              ┌───────────────────────────────────┼───────────────────────────────────┐
              ▼                                                                       ▼
     模式 C：全网劝退                                                        模式 D：候选终审
     - 普遍高价 / 技术更迭临界期                                             - 用户已提供候选型号列表
     - 讲清为何现阶段不宜购买                                                - 保留 / 替换 / 淘汰终审表格
     - 给出过渡替代方案与观望时机                                            - 点明哪款最稳、哪款属于溢价
```

## 📚 12 大常见品类参考清单

**Shopaholic 预置了 12 个常见大类的基础工艺标准与避坑提示**（详见 `references/category-checklists.md`）。遇到清单外的细分品类，智能体会自动实时检索调研：

- 🍎 **食品生鲜与酒水饮料**：冷冻干燥(FD) vs 喷雾干燥(SD)、原切肉 vs 调理拼接肉、配料表清洁度。
- 📱 **手机、电脑与智能数码**：屏幕面板素质与调光、处理器持续功耗释放、固态颗粒类型(TLC vs QLC)。
- 🧊 **大家电与厨卫电器**：热泵烘干 vs 冷凝烘干、冰箱独立双循环防串味、空调冷凝管材质、净水器通用滤芯 vs 专用锁水。
- 🧹 **生活电器与清洁个护**：扫地机避障导航、洗地机高温热风烘干 vs 冷风发臭、主动割毛防缠绕、吹风机温控防烫。
- 💄 **美妆护肤与洗护日化**：有效活性成分浓度促渗、特殊化妆品资质溯源、防概念性微量添加、刷酸耐受提醒。
- 🍼 **母婴用品、玩具与儿童安全**：3C 认证与安全座椅标准(GB 27887/i-Size)、食品级接触材质、分段式安全座椅。
- 🛏️ **家居建材、家具与家纺床垫**：防爆气压棒认证、床垫弹簧与环保填充层、新国标 ENF 级环保检测、大件退换运费。
- 🏃 **运动户外、鞋服与箱包**：防水透湿膜技术(GORE-TEX等)、羽绒保暖蓬松度、湿滑路面防滑大底、面料压胶寿命。
- 🚗 **汽车用品、车载电子与出行装备**：行车记录仪传感器与耐高温超级电容、安全头盔 3C 认证、应急启动电源安全规范。
- 🐱 **宠物食品、用品与智能硬件**：主粮鲜肉配比与检测报告、智能喂食器水电分离结构、自动猫砂盆防夹保护。
- 🎮 **影音娱乐、游戏硬件与桌面外设**：机械键盘与磁轴稳定性、鼠标传感器主控、投影仪原生分辨率与真实流明。
- 🩺 **健康监测、个护仪器与家用器械**：家用二类医疗器械资质(血压计/血糖仪/制氧机)、测量精度与专用耗材成本。
