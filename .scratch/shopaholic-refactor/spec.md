# System Specification: Shopaholic 循证购物决策顾问重构规范

## Problem Statement

用户在借助 AI 进行购物决策时，现有的 `shopaholic` 存在以下 5 个系统性缺陷：
1. **问卷互斥导致逻辑死锁与机械误杀**：单轮问卷强行将用户的探索偏好（如“下巴机位 + 免剪辑”）当作不可逆的物理硬性红线，教条化执行“先排除后排序”，导致用户原本想了解的品类（如全景相机）被直接彻底淘汰。
2. **检索过窄与时效性不足导致事实性幻觉（Hallucination）**：AI 过度信任预训练权重的内部记忆，在面对用户具体品牌质询（如“大疆全景相机”）时未做防御性检索，自信断言“大疆根本没有全景相机”，产生严重的事实性错误与说教。
3. **大样本证据一刀切误杀硬核新品与黑马**：过分强调大样本长期差评数据，导致刚发布的高用料旗舰新品（如 Osmo 360）或供应链扎实的小众黑马被简单粗暴地降级或抹杀。
4. **纠错响应中的情绪化谄媚与逻辑断裂**：在被用户纠错后，AI 极易发生 180 度大反转，从“完全否定”转为“盲目吹捧”，丧失了对新品软件生态成熟度等客观短板的冷峻审视。
5. **用户约束漂移时缺乏代价守恒闭环**：当用户中途推翻前设（如“放弃下巴机位改选全景”）时，AI 未能主动提示新选择带来的工作量、配件成本与使用门槛等新增代价。

---

## Solution

构建一套**防御性检索驱动、两阶段偏好诱导、双轨证据分档与抗谄媚**的完整决策支持系统：
1. **两阶段动态交互模型**：第一阶段萃取物理硬约束与好恶特质（Preferences & Dislikes）；第二阶段由用户自选交付视角（全局综合排序 / 细分场景矩阵 / 黑名单绝对剔除），避免格式僵化与品类误杀。
2. **强制防御性检索与品牌全系图谱拉网扫描**：禁止基于内部记忆断言“某品牌无某产品”，针对品牌质询强制 2 轮以上时效性防御检索；推荐前必须拉网扫描头部品牌全谱系在售产品（3+2+1 梯队）。
3. **双轨制证据分档矩阵（A 档成熟池 + B 档新品/黑马观察池）**：扫描 10~15 款，报告呈现 6~10 款；既保障大样本主流款的稳妥性，又给高规格新品和硬核黑马留出带风险声明的展示窗口（BOM 白盒化准入）。
4. **冷峻抗谄媚与事实接入协议**：事实纠错走“中立接入 -> 独立核验 -> 重新跑通矩阵 -> 给出软硬件综合客观评价”，杜绝谄媚和两极反转。
5. **约束漂移时代价守恒定律（Cost of Pivoting）**：场景切换时强制置顶输出工作流、动力学、算力与光学易损四维前置代价清单。
6. **多轮消融/增添实验基准体系**：通过多子代理（Subagent）并行运行消融实验（单项移除/单项增添），验证新机制的显著性增益与格式稳定性。

## User Stories

1. As a 摩托车骑手，I want 在初始输入模糊需求时接受第一阶段精准问卷，so that AI 能准确提取我的安装尺寸、预算边界以及对“重量/后期剪辑/画质”的深层偏好。
2. As a 纠结于多种机位与形态的消费者，I want 在第二阶段选择“按细分场景矩阵”或“综合优先级”呈现报告，so that 我不会因为选了某一个偏好而导致其他想了解的跨界品类被一刀切淘汰。
3. As a 追求买后不后悔的用户，I want 能够明确指定我极度厌恶的特征（如“拒绝翻转屏”、“拒绝高碎镜风险”），so that 系统能在最终候选池中将此类商品直接做黑名单剔除。
4. As a 关注市场最新动态的用户，I want 询问“大疆是否有全景相机”时 AI 强制调用最新全网检索，so that AI 不会因为其过时的内部记忆而向我提供“该产品不存在”的虚假信息。
5. As a 严谨的消费者，I want AI 在进入选购推荐前拉网扫描主要品牌的完整在售谱系，so that 最终推荐池不会遗漏最新发布或更具竞争力的在售型号。
6. As a 关注性价比与新技术的极客用户，I want 在选购矩阵中看到单独划分的【B 档：高潜能·硬核新品/黑马观察池】，so that 我既能了解到最新高配置产品，又能清楚知晓其“长期耐用度与软件成熟度仍在观察”的客观风险。
7. As a 追求绝对稳妥的普通家庭用户，I want 在【A 档：大样本成熟验证池】中直接挑选经过市场长期检验的机型，so that 我无需承担任何早期品控或售后网点缺失的风险。
8. As a 提供事实纠错的用户，I want AI 在接收到我的型号提醒后冷静核验并客观评估，so that AI 既不会傲慢反驳我，也不会毫无原则地 180 度谄媚吹捧该产品。
9. As a 在对话中改变主意（如推翻机位或预算）的用户，I want AI 强制给出【前置代价确认】，so that 我能在切换方案前清楚意识到新方案带来的后期剪辑负担或配件成本增加。
10. As a Skill 维护者与开发者，I want 拥有一套多子代理消融与增添实验基准，so that 我能用量化指标证明每一条新规则对防幻觉、防误杀与候选覆盖面的显著提升。

## Implementation Decisions

1. **核心文件体系设计**：
   - 核心规则入口：`skills/shopaholic/SKILL.md`（定义总原则、两阶段交互模式、四大输出模式、核心红线）。
   - 专项协议一：`skills/shopaholic/references/research-protocol.md`（重构为包含防御性检索、品牌全系扫描、信源四级过滤的完整检索协议）。
   - 专项协议二：`skills/shopaholic/references/evidence-and-risks.md`（定义 A/B 双轨证据分档、致命缺陷一票否决、低保有量观察期机制）。
   - 专项协议三：`skills/shopaholic/references/category-checklists.md`（更新典型品类的物理约束与前置代价守恒清单）。
2. **两阶段问答状态机契约**：
   - Phase 1（画像萃取）：生成 2~4 个关于硬约束与好恶倾向的精准问题。
   - Phase 2（视角确认）：基于 Phase 1 萃取结果，通过 `ask_user_question` 提供 3 个互斥的决策交付视角（全局优先级排序 / 细分场景矩阵 / 黑名单绝对剔除）。
3. **防御性检索拦截器（Defensive Search Invariant）**：
   - 规则强约束：凡出现“A 品牌有没有 B 产品”或“某具体型号评测”的输入，禁止直接生成肯定/否定断言，前置必须执行 2 组以上包含当前年份及全网技术社区的多角度搜索。
4. **双轨证据分档架构（Dual-Track Matrix）**：
   - 弃用原有的单一梯队挤压模式，强制分为 `【A 档：大样本成熟验证池】`（3~5 款）与 `【B 档：高潜能·硬核新品/黑马观察池】`（3~5 款），并在 B 档表格下方强制输出【成熟度与售后妥协声明】。
5. **反谄媚数据接入协议（Anti-Sycophancy Protocol）**：
   - 确立“冷峻客观”对话范式，纠错时禁止道歉与过度恭维，直接输出重新跑通的客观比对。

## Testing Decisions

- **外部行为测试**：通过端到端多轮对话场景（摩托车骑行、大家电、数码）验证防幻觉率、跨界品类保全率、新品识别率与代价披露完整度。
- **消融实验（Ablation）**：分别移除防御性检索、两阶段视角、双轨分档与代价守恒机制，验证量化指标的显著性差异。

## Out of Scope

- 接入需要私有 Cookie 的封闭电商爬虫 API。
- 纯代码编写与非选购领域的学术翻译。
