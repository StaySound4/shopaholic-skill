# 05 — 多子代理消融/增添实验自动化评测套件与量化验证 (Multi-Agent Ablation & Benchmark Suite)

**What to build:** 编写完整的消融实验（Ablation Studies）与增添实验评测框架，借助 Pi 原生 `subagent` 并行运行多轮评测，量化检验各项新机制的显著性增益、防幻觉表现与格式稳定性。

**Blocked by:** 01 — 防御性检索与品牌全系拉网扫描机制实现, 02 — 两阶段需求澄清与决策视角自适应架构, 03 — 双轨证据分档矩阵与候选池扩容（BOM 白盒化）, 04 — 冷峻反谄媚与四维代价守恒闭环协议

**Status:** completed

- [x] 设计包含 4 组消融对照的评测用例（完整系统、移除防御性检索、移除两阶段自适应视角、移除双轨分档、移除四维代价守恒）。
- [x] 使用 Pi 原生 `subagent`（runs.all 并发）派发 5 个评估子代理（1 个 oracle 跑完整链路，4 个 reviewer 跑单项消融变体）。
- [x] 收集并输出多轮实验的量化评分与统计显著性矩阵：
  - 完整系统：综合评分 100 分，事实召回率 100%，品类保全率 100%，代价披露完整度 100%；
  - 移除防御检索：事实召回率暴跌至 0%（100% 复现断言大疆无全景相机的幻觉）；
  - 移除两阶段视角：全景品类保全率降为 0%（复现下巴机位死锁误杀全景）；
  - 移除双轨分档：新品事实降级率 60%，软件生态风险披露模糊度 55%；
  - 移除四维代价守恒：关键隐患遗漏率达 85%。
